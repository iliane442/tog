# Icônes des sorts

Les 162 icônes ont été créées avec ImageGen intégré. Les onze planches PNG utilisent des cases de 96 × 96 pixels. Le jeu associe les cases à leurs identifiants dans `scripts/ui/icones_sorts.gd`.

Pour les sept premières planches, chaque prompt concatène le préambule commun et les quatre lignes de la planche. Les six planches après `techniques.png` incluent également l’instruction de référence. Les quatre planches de techniques de classe ont leur propre préambule.

## Préambule commun

```text
Use case: stylized-concept. Asset type: one production sprite atlas for a pirate fantasy tactical RPG spellbook in Godot. A square 1024x1024 atlas of exactly 16 distinct icons in a mathematically even 4-column by 4-row grid, in the order specified. Every icon is centered in its cell at x/y 12.5%, 37.5%, 62.5%, 87.5% of the canvas. Repeated dark midnight teal squarish tile with small clipped corners and a thin warm dark bronze rim, about 82% of each cell. Entire gutter and outer margin truly transparent. All 16 tiles the same size and aligned to the same invisible grid. Clear one dominant symbol per icon and generous dark tile space around it. Make dense cluster-based retro 32-bit RPG pixel art, hand-placed staircase pixels, limited well-separated palette, dark outlines and warm upper-left highlights, highly legible at 32 pixels. Bold distinct silhouettes with crisp edges and small details. Consistent value, finish and apparent scale throughout the pack. No text, no numbering, no lettering, no grid lines, no drop shadows outside the tiles, no photorealism or blurred glow.
```

```text
Input image: style and grid reference for the existing series. Match its midnight teal and bronze clipped-corner tiles, crisp pixel clusters and overall spacing closely. Redraw every symbol as specified below. Make a single atlas sheet containing all and only these sixteen icons.
```

```text
Use case: stylized-concept. Asset type: one production sprite atlas for the class skills of an existing pirate tactical RPG. Input image: reference for the exact 4-column by 4-row square layout, identical shield-shaped clipped square tiles with matte midnight teal backgrounds and a narrow weathered bronze rim, crop spacing, proportions, and crisp pixel art style. Keep sixteen identically sized tiles precisely aligned to the four columns and four rows. The gutters and exterior are genuinely alpha transparent like the reference. Inside each tile redraw the requested symbol at the same common scale with bold hand-pixelled shapes, thick dark contours, selective highlights from the upper-left, strong contrast and clear silhouettes at 32 px. Exactly one symbol per tile, generous spacing inside the rim. No text, letters, numbering, outlines outside the tiles, or typography. All subjects below are original fantasy game icons.
```
