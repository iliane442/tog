# Illustrations de Fushia

ImageGen intégré a produit le navire, les personnages et les décors ou animaux de cette scène. Les éléments ont été découpés et mis à l’échelle pour Godot à partir des planches générées, avec les items et les bateaux du projet comme références visuelles.

La scène réunit plusieurs moments de l’anime dans une même carte jouable. Le navire est une interprétation conçue autour d’un pont explorable. [Fushia et l’équipage de Shanks](https://one-piece.com/story/east_blue/index.html) · [Le mont Corvo et la famille de Dadan](https://one-piece.com/character/Monkey_D_Garp/index.html)
